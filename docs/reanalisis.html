Paquetes y datos

Código 
library(agricolae)
library(inti)
library(multcomp)
library(tidyverse)   # al final, para que select() sea el de dplyr

camote <- read_csv("datos/camote_virus.csv", show_col_types = FALSE) |>
  mutate(virus = factor(virus, levels = c("oo", "cc", "ff", "fc"),
                        labels = c("Sano", "SPCSV", "SPFMV", "Complejo")))

1. Exploración

Código 
camote |>
  group_by(virus) |>
  summarise(media = mean(yield), de = sd(yield), min = min(yield), max = max(yield)) |>

  knitr::kable(col.names = c("Tratamiento", "Media (kg)", "DE", "Mín", "Máx"))
Tratamiento Media (kg) DE Mín Máx
Sano 36.90 4.30 32.1 40.4
SPCSV 24.40 3.61 21.7 28.5
SPFMV 36.33 7.33 28.0 41.8
Complejo 12.87 2.16 10.6 14.9
Código 
ggplot(camote, aes(virus, yield)) +
  stat_summary(fun = mean, geom = "col", fill = "#7FB77E", width = 0.6) +
  geom_point(size = 2.5) +
  labs(x = NULL, y = "Rendimiento (kg/parcela)") +
  theme_minimal(base_size = 13)

A simple vista, el complejo viral produce mucho menos que el resto, y las plantas sanas y las infectadas solo con SPFMV rinden parecido.

2. ANOVA

Modelo del DCA:

\[Y_{ij} = \mu + \tau_i + \varepsilon_{ij}\]

Código 
modelo <- aov(yield ~ virus, data = camote)
anova(modelo)
Analysis of Variance Table

Response: yield
          Df  Sum Sq Mean Sq F value    Pr(>F)    
virus      3 1170.21  390.07  17.345 0.0007334 ***
Residuals  8  179.91   22.49                      
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

Con p < 0.001 hay diferencias entre tratamientos. Esto coincide con el análisis original.

Tamaño del efecto

El p-valor dice si hay diferencias, pero no qué tan grandes son. El eta cuadrado (η²) indica qué proporción de la variación total se explica por el virus:

Código 
tabla <- anova(modelo)
eta2 <- tabla["virus", "Sum Sq"] / sum(tabla[, "Sum Sq"])
round(eta2, 2)
[1] 0.87

El virus explica cerca del 87 % de la variación del rendimiento. Es un efecto muy grande.

Coeficiente de variación

Código 
cv.model(modelo)
[1] 17.1666

Un CV menor a 20 % es aceptable para experimentos de campo.

3. Supuestos

Código 
shapiro.test(residuals(modelo))         # normalidad de residuos

W = 0.95878, p-value = 0.7663
Código 
bartlett.test(yield ~ virus, camote)    # homogeneidad de varianzas

    Bartlett test of homogeneity of variances

data:  yield by virus
Bartlett's K-squared = 2.3886, df = 3, p-value = 0.4958
Código 
plot_diagnostic(data = camote, formula = yield ~ virus) |>
  cowplot::plot_grid(plotlist = _, ncol = 2)

Ambas pruebas dan p > 0.05, así que no hay evidencia de que se violen los supuestos. Con solo 12 datos estas pruebas tienen poca potencia, por eso se confirma el resultado con una prueba no paramétrica, que no necesita normalidad:

Código 
kruskal.test(yield ~ virus, data = camote)

    Kruskal-Wallis rank sum test

data:  yield by virus
Kruskal-Wallis chi-squared = 8.6923, df = 3, p-value = 0.03367

Kruskal-Wallis también da p < 0.05. El efecto del virus se confirma por dos caminos distintos.

4. Comparación de medias: ¿cambian las conclusiones?

LSD de Fisher (análisis original)

Código 
lsd <- LSD.test(modelo, "virus")
lsd$groups
            yield groups
Sano     36.90000      a
SPFMV    36.33333      a
SPCSV    24.40000      b
Complejo 12.86667      c

Tukey HSD (más estricta)

Código 
tukey <- HSD.test(modelo, "virus")
tukey$groups
            yield groups
Sano     36.90000      a
SPFMV    36.33333     ab
SPCSV    24.40000     bc
Complejo 12.86667      c

Comparación lado a lado

Código 
full_join(
  lsd$groups   |> rownames_to_column("virus") |> dplyr::select(virus, media = yield, LSD = groups),
  tukey$groups |> rownames_to_column("virus") |> dplyr::select(virus, Tukey = groups),
  by = "virus"
) |>
  mutate(media = round(media, 1)) |>
  knitr::kable(col.names = c("Tratamiento", "Media (kg)", "LSD", "Tukey"))
Tratamiento Media (kg) LSD Tukey
Sano 36.9 a a
SPFMV 36.3 a ab
SPCSV 24.4 b bc
Complejo 12.9 c c

Aquí cambia la conclusión:

  • Con LSD hay tres grupos bien separados: (Sano, SPFMV) > SPCSV > Complejo.
  • Con Tukey los grupos se traslapan: SPCSV ya no se distingue de SPFMV ni del complejo viral.

La diferencia se debe a que LSD no corrige por hacer 6 comparaciones a la vez. Tukey sí lo hace y por eso es más conservadora. Con solo 3 repeticiones, las diferencias intermedias no son tan claras como sugiere el análisis original.

5. La pregunta correcta: cada virus contra el testigo

El objetivo del experimento es saber cuánto daña cada virus respecto a las plantas sanas. Para eso no hace falta comparar todos contra todos: la prueba de Dunnett compara cada tratamiento solo con el testigo, y así gana precisión.

Código 
dunnett <- glht(modelo, linfct = mcp(virus = "Dunnett"))
summary(dunnett)

     Simultaneous Tests for General Linear Hypotheses

Multiple Comparisons of Means: Dunnett Contrasts


Fit: aov(formula = yield ~ virus, data = camote)

Linear Hypotheses:
                     Estimate Std. Error t value Pr(>|t|)    
SPCSV - Sano == 0    -12.5000     3.8721  -3.228   0.0297 *  
SPFMV - Sano == 0     -0.5667     3.8721  -0.146   0.9976    
Complejo - Sano == 0 -24.0333     3.8721  -6.207   <0.001 ***
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
(Adjusted p values reported -- single-step method)
Código 
confint(dunnett) |>
  broom::tidy() |>
  mutate(contrast = str_remove(contrast, " - Sano")) |>
  ggplot(aes(x = estimate, y = contrast)) +
  geom_vline(xintercept = 0, linetype = "dashed") +
  geom_pointrange(aes(xmin = conf.low, xmax = conf.high), color = "#C0392B") +
  labs(x = "Diferencia con plantas sanas (kg/parcela)", y = NULL) +
  theme_minimal(base_size = 13)

6. Pérdida de rendimiento

Código 
sano <- mean(camote$yield[camote$virus == "Sano"])

camote |>
  group_by(virus) |>
  summarise(media = mean(yield)) |>
  mutate(perdida_kg = sano - media,
         perdida_pct = perdida_kg / sano * 100) |>
  filter(virus != "Sano") |>
  mutate(across(where(is.numeric), \(x) round(x, 1))) |>
  knitr::kable(col.names = c("Virus", "Media (kg)", "Pérdida (kg)", "Pérdida (%)"))
Virus Media (kg) Pérdida (kg) Pérdida (%)
SPCSV 24.4 12.5 33.9
SPFMV 36.3 0.6 1.5
Complejo 12.9 24.0 65.1

Conclusiones

  1. El efecto del virus es real y muy grande: lo confirman el ANOVA, Kruskal-Wallis y un η² de 0.87.
  2. El complejo viral (SPFMV + SPCSV) es el más dañino: reduce el rendimiento en cerca de 65 % respecto a las plantas sanas.
  3. SPCSV solo también reduce el rendimiento de forma significativa (alrededor de 34 %, Dunnett p ≈ 0.03).
  4. SPFMV solo no reduce el rendimiento: su diferencia con las plantas sanas es casi cero.
  5. La prueba elegida importa: la LSD del análisis original muestra grupos más separados de lo que permiten los datos. Con Tukey, SPCSV no se distingue claramente de los otros virus. Para este experimento, Dunnett es la prueba más adecuada porque responde directamente la pregunta.
  6. Recomendación: con 3 repeticiones el experimento tiene poca potencia. En un nuevo ensayo convendría usar al menos 5 repeticiones.

## Paquetes y datos

```{r}
#| label: paquetes
library(agricolae)
library(inti)
library(multcomp)
library(tidyverse)   # al final, para que select() sea el de dplyr

camote <- read_csv("datos/camote_virus.csv", show_col_types = FALSE) |>
  mutate(virus = factor(virus, levels = c("oo", "cc", "ff", "fc"),
                        labels = c("Sano", "SPCSV", "SPFMV", "Complejo")))
```

## 1. Exploración

```{r}
#| label: resumen
camote |>
  group_by(virus) |>

  mutate(across(where(is.numeric), \(x) round(x, 2))) |>
  knitr::kable(col.names = c("Tratamiento", "Media (kg)", "DE", "Mín", "Máx"))
```

```{r}
#| label: fig-exploracion
#| fig-cap: "Rendimiento por parcela según el virus inoculado. Cada punto es una repetición."
#| fig-width: 7

  geom_point(size = 2.5) +
  labs(x = NULL, y = "Rendimiento (kg/parcela)") +
  theme_minimal(base_size = 13)
```

A simple vista, el complejo viral produce mucho menos que el resto, y las plantas sanas y las infectadas solo con SPFMV rinden parecido.

El virus explica cerca del **87 %** de la variación del rendimiento. Es un efecto muy grande.

Un CV menor a 20 % es aceptable para experimentos de campo.
